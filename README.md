# Hoop City '17
Browser park basketball: https://icodewithvibes.github.io/hoopcity17/

Online: Online Room > Create room, share the 4-letter code; friends open the same link, Online Room, type the code. Peer-to-peer (PeerJS/WebRTC), no sign-in. If the host leaves, another player takes over.

Saves stay in your browser (no account). Settings > Your save: copy a save code to move it to another device.
